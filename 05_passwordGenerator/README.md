# Password Generator

A small React + Vite app to generate random passwords.

## Features
- Adjust password length (6 to 20)
- Toggle numbers
- Toggle special characters
- Copy generated password to clipboard

## Tech
- React
- Vite
- Tailwind CSS

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
